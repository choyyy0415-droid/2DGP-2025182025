# Drill 8 애니메이션 뷰어

수업 자료에 있던 `SamuraiSheet.png`와 `TUK_GROUND.png`를 사용합니다.

```powershell
cd LEC08
python animation_viewer.py
```

창을 닫거나 `Esc` 키를 누르면 종료됩니다.

## 구현 내용

- 걷기와 달리기는 서로 다른 속도로 화면을 왕복 이동
- 점프는 이동하면서 포물선으로 상승·하강
- 공격은 앞으로 빠르게 내밀었다가 원위치
- 각 동작을 5회 반복하고 1초 쉰 뒤 다음 동작 재생
- 모든 동작을 순서대로 무한 반복
- 캐릭터를 화면 높이의 절반 이상으로 확대 표시
- 사무라이 시트의 실제 걷기·달리기·점프·공격 프레임을 사용
